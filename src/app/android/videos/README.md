# App walkthrough videos

Screen recordings of the debug build on the `Pixel_10` emulator (1080×2424,
recorded at 720×1616, touches shown). Premium videos use the debug tier
override (see `../README.md`), not a real code. Account requests go to the
production backend with invalid input only.

Videos 02 and 05–08 are cut together from short segments, so the trainer timer
jumps between cuts. The full placement test (60 questions) was answered off
camera; video 06 shows its start and its result.

| Video | Use case |
|---|---|
| [01-landing-tour](01-landing-tour.mp4) | First start: landing page, switching the UI language RU → EN → DE, scrolling through level picker, Einstufungstest teaser, locked Premium hub, legal footer |
| [02-free-a1-session](02-free-a1-session.mp4) | Free A1 session with the 10-minute countdown: fill-in with the ß key, wrong → right multiple choice, word order with 💡 Tipp, a wrong check and retry, adaptive repeat of a missed question, result screen with "Themen mit Fehlern" |
| [03-profile-and-account](03-profile-and-account.mp4) | Mini profile for free users → "Anmelden / Code aktivieren": invalid e-mail (local check), invalid login link and invalid activation code (production backend errors) |
| [04-legal-pages](04-legal-pages.mp4) | AGB, Datenschutz, Impressum and switching between them |
| [05-premium-topic-session](05-premium-topic-session.mp4) | Premium hub (Nach Thema / Wortschatz), topic session with count-up timer and ×2 XP, 📚 Grammatik-Tipp in RU/EN/DE after a wrong answer, dictionary cards (Kaninchen → кролик, süß → cute), result |
| [06-premium-dashboard-schwaechen-placement](06-premium-dashboard-schwaechen-placement.mp4) | Activity calendar and Schwächen card on the landing page, Schwächen session, Einstufungstest start, its result (A1–B2 breakdown, "Dein Niveau: B2"), level shown on the landing page |
