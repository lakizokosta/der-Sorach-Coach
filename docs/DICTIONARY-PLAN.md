# Словарь тренажёра — план и правила

**Статус:** 🟢 **этап 1 — инфраструктура** (build, локальный lookup, lemma maps). Переводы наполняются через `vocabulary-seed.json` + `npm run dictionary:build:fetch`.  
**Ворота (gate):** см. [CONTENT-FILLING.md](./CONTENT-FILLING.md) — словарь начинаем, когда банк вопросов A1–B2 закрыт по чеклисту тем.  
**Зафиксировано:** 2026-06-09 (решение с владельцем продукта).

## Зачем ждать наполнения контента

1. Список уникальных слов из `src/questions/**/*.md` ещё растёт — преждевременный словарь придётся переделывать.
2. Совместный анализ «что не переводить» имеет смысл только на **финальном** корпусе текстов.
3. Сейчас перевод идёт через MyMemory (`src/utils/dictionary.js`) — временное решение; локальный словарь заменит его позже.

**Команда для оценки корпуса (когда контент готов):**

```bash
npm run questions:stats    # покрытие тем
# + скрипт извлечения лексики (будет добавлен на этапе реализации)
```

## Принципы словаря (согласовано)

### 1. Слова без перевода (не кликабельны / без попапа)

| Категория | Правило | Примечание |
| --- | --- | --- |
| **Местоимения** | Все формы, все падежи — **без перевода** | `ich`, `mir`, `mich`, `du`, `dir`, `sie`, `ihnen` … |
| **Артикли** | Без перевода | Уже частично в `stopwords.js` |
| **Предлоги, союзы, частицы** | Без перевода | `und`, `aber`, `nicht`, `zu`, `mit` … |
| **Числительные** | Без перевода | `eins` … `million`, порядковые |
| **Вспомогательные / модальные** | Формы без перевода | `bin`, `ist`, `haben`, `kann`, `muss` … |
| **«Слишком лёгкие» / очевидные** | Без перевода | **Совместный анализ после наполнения** — см. §4 |

Текущий черновик стоп-слов: `src/data/stopwords.js` (`DICT_STOPWORDS`). При реализации словаря этот список станет **источником истины** для «не переводим» и будет расширен (все падежи местоимений и т.д.).

### 2. Глаголы — только инфинитив

| В тексте | В словаре / попапе |
| --- | --- |
| `antworte`, `antwortet`, `antwortete` | **antworten** → отвечать |
| `gehe`, `ging`, `gegangen` | **gehen** → идти |

- Спряжённые формы **не переводим как отдельные леммы**.
- В попапе показываем: форма в предложении + **Infinitiv** + перевод инфинитива.
- Неправильные глаголы — таблица лемм (этап реализации).

### 3. Прилагательные — только основная форма

| В тексте | В словаре / попапе |
| --- | --- |
| `groß`, `große`, `großer`, `großes` | **groß** → большой |
| `schneller`, `am schnellsten` | **не переводим** (Komparativ / Superlativ) |
| `besser`, `beste` | **не переводим** (степени сравнения) |

- Склонённые формы приводим к **Positiv / Grundform**.
- Komparativ и Superlativ — в стоп-лист (как местоимения): клик не даёт перевода **или** показывает только «→ groß (Grundform)» без отдельного перевода степени — **уточнить на совместном разборе**.

### 4. Совместный анализ — «лёгкие / логичные» слова

**Когда:** после закрытия всех уровней и тем (gate в CONTENT-FILLING).

**Критерии для исключения из перевода:**

- Интернационализмы / прозрачные заимствования: `Auto` ↔ авто, `Hotel`, `Telefon` …
- Слова с очевидным переводом для целевой аудитории (русскоязычные): `Mutter`, `Vater` (спорно — вынести в таблицу)
- Слова, которые в тренажёре **только** как грамматический объект (артикль, окончание), а не как лексика

**Процесс:**

1. Скрипт выгружает все уникальные токены из банка вопросов → `docs/dictionary-wordlist.csv` (или `.md`).
2. Автоматическая разметка: местоимение / артикль / глагол-форма / Komparativ / кандидат в словарь.
3. **Совместный проход** по списку: пометки `SKIP` | `DICT` | `INFINITIV-ONLY` | `LEMMA-ADJ`.
4. Итог → `src/data/vocabulary.json` + обновление `stopwords.js`.

## Где будет храниться (технически, после реализации)

| Файл | Назначение |
| --- | --- |
| `src/data/stopwords.js` | Не кликабельно / без перевода |
| `src/data/vocabulary.json` | Лемма → `{ ru, en, pos?, gender? }` |
| `src/data/verbLemmas.json` | Форма → инфинитив (или общий модуль лемматизации) |
| `src/utils/dictionary.js` | Lookup: стоп → лемма → локальный словарь → API fallback |

**Нагрузка на тренажёр:** словарь подгружается **lazy** при первом клике (~30–100 KB gzip на фоне ~1,2 MB вопросов). На рендер вопросов не влияет.
