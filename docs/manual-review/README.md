# Manuelle Fragenprüfung

Checklisten aller Fragen aus `src/questions/`, gruppiert nach Niveau und Thema.

**Aktualisieren:** `npm run questions:export-review`

## So prüfen

1. Thema aus der Tabelle unten öffnen.
2. Jede Frage lesen — Satz, Hinweis, Antworten.
3. `- [ ] OK` abhaken oder unter **Fehler / Anmerkung** notieren.
4. Fehler im Quellfile unter `src/questions/<LEVEL>/<TOPIC>/` korrigieren.
